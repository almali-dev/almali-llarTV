## Specs

- S1 Owner (verbatim): "llença les skills, de seguretat, performance i gui sobre el projecte", then "Vull que els implementis tots." The three audit passes (sentinel-security, bolt-performance, palette-ux, read as skills but adapted: they are written for plex_smart_cache, a Python/Flask project) each proposed one change; all three are implemented here.
- S2 Security: `DailyWallpaper.slides(File)` builds `new File(dir, name)` from the name read in `wallpapers.txt` without validating it (DailyWallpaper.java:103). A name containing `../` escapes the directory, so Home and the screensaver can show any image on the shared volume. Only `../` escapes: an absolute child is resolved under the parent by `java.io.File(File,String)` (verified by running it), so the fix is about traversal, not absolute paths. The rule: a listed name is used only when it matches exactly what `fileName()` writes, `wallpaper-[0-9a-f]+\.jpg`; any other line is skipped, and the legacy single-file fallback keeps working.
- S3 Performance: `loadWallpaper()` (HomeActivity.java:1403) decodes the full 1920x1080 JPEG and computes its average colour synchronously, and `onResume` calls it (HomeActivity.java:225), so that work is inside the measured cold start. The decode and the average move off the main thread, like `BingDream.java:265` already does; the resolve and the stamp stay on the main thread, and a result is applied only when its stamp is still the current one. Home's first frame does not need the bitmap. The gain is an estimate (30-100 ms) until a paired reference-TV measurement says otherwise; the measurement decides whether the change stays.
- S4 Interface, saved value: in the settings value list, `applyPanelFocus` (SettingsActivity.java:559) paints only the focused option, so after moving the focus nothing says which value is saved. The saved option is marked with the existing ACCENT colour and weight 500. The reset row and the hidden-apps row are excluded, because their `selected` is not a saved value (Cancel first, and always 0).
- S5 Interface, no Internet: the Wi-Fi pill shows the network name whenever `isConnected()` is true (HomeActivity.java:1381), so on a network without Internet it claims everything is fine while the weather and news cards quietly disappear. Home already learns whether the network is validated (NET_CAPABILITY_VALIDATED, HomeActivity.java:274) and uses it only to retry downloads. The pill says "Sense Internet" / "Sin Internet" / "No Internet" when the network is connected but not validated; the state is unknown until the first capability callback, and an unknown state keeps the current text rather than claiming a problem.
- S6 Version and documentation: `versionCode 9`, `versionName '1.8'` (the project tags `vMAJOR.MINOR`, CONTRIBUTING.md:47; these are pre-existing defects plus user-visible changes, not a patch of v1.7). The CHANGELOG gets a `[1.8]` section; `docs/performance/v1.8.md` records the paired measurement of S3; the README keeps its badge and size summary.
- S7 Delivery: the release is `v1.8` (versionCode 9) with the exact tested APK, published and verified over HTTPS, the milestone closed and the roadmap updated, exactly as v1.7 did. TV acceptance and the release happen with the owner's go-ahead.
