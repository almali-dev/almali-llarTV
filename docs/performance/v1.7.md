# LlarTV v1.7 performance (emulator paired; reference TV pending)

**Status: the emulator paired check is inside every allowance, and the quote acceptance passes in the three
languages.** v1.7 changes only the quote corpora (675 short motivational lines per language) and the version. The
emulator numbers are a regression guard; the reference-TV pair is the release gate (see
[the targets](baseline-v1.0.md#targets)) and is pending the owner's go-ahead.

## Setup

- Target: Android TV emulator `emulator-5554`, AVD `tv11` (the same AVD as v1.6), AOSP TV on x86, Android 11
  (SDK 30), headless, cold boot without saving a snapshot. Same fixture for both versions (Bing wallpaper, default
  dock, Catalan interface), written again after every install; the original `home.conf` was restored at the end.
- Baseline: [published v1.6 APK](https://github.com/almali-dev/almali-llartv/releases/download/v1.6/LlarTV.apk), downloaded
  over HTTPS, 4,266,913 bytes, SHA-256 `d69e594f8f40098429053881b25e594454ac318e5da1858aee87369c20cc89a3` (matches
  [v1.6 performance](v1.6.md#release)).
- Candidate: debug APK built from `feat/v1-7` `42bb798` in a clean detached worktree, 4,227,233 bytes, SHA-256
  `ac05a99e0e8b4939c792059159067eae90c48181995c5ede5b1d6c38cf6da019`; its three quote assets match the source
  files byte for byte (675 rows each). Same signing certificate, installed in place with `install -r -d`.
- Procedure, unchanged from v1.6: `scripts/measure.sh --serial emulator-5554 --apk <apk> --runs 5` (one discarded
  warm-up, five cold starts, five returns from another app, three PSS samples) after a 20 s settle following each
  install. Two alternating rounds: baseline, candidate, baseline, candidate.

## Results

Paired comparisons use the mean of each version's two round medians, as in v1.6.

| Metric | v1.6 (a · b) | v1.7 (a · b) | Difference (mean of the run medians) | Paired allowance | Result |
| --- | --- | --- | --- | --- | --- |
| Cold start, median ms | 1,503 · 1,594 | 1,487 · 1,540 | −35 ms (−2.3%) | +150 ms and +15% | Inside |
| Home return, median ms | 164 · 131 | 117 · 109 | −35 ms | +40 ms and +40% | Inside |
| RAM, TOTAL PSS, median KB | 39,382 · 41,420 | 41,171 · 40,856 | +613 KB (+1.5%) | +4,096 KB and +10% | Inside |
| APK bytes | 4,266,913 | 4,227,233 | −39,680 (−0.93%) | +5% | Inside |

Raw samples — cold start: v1.6 a 1529 1560 1440 1503 1429, b 1720 1569 1622 1594 1438; v1.7 a 1459 1499 1500 1487
1458, b 1540 1488 1589 1634 1468. Home return: v1.6 a 164 167 122 225 97, b 103 131 162 148 105; v1.7 a 104 117 117
201 88, b 91 213 93 109 138. PSS: v1.6 a 39868 39382 39362, b 41940 41420 41408; v1.7 a 41675 41171 41163, b 42259
40856 40796.

The absolute cold starts are higher than in the v1.6 emulator run (about 1.5 s against 0.56 s) because this run
booted the AVD cold instead of from its snapshot and the host was under a different load; both versions were
measured in the same session and alternated, so the paired difference is the comparable figure. The Home return
uses `explicit-resume` because the emulator's default home is not LlarTV; the default home was restored after
each run.

## Quote acceptance (S2, S6)

On the candidate, the emulator clock was set with `cmd alarm set-time` to a day where
`floorMod(epochDay, 675)` selects the planned line, the interface language was set in `home.conf`, Home was
restarted, and a screenshot and a `uiautomator` dump were taken; the clock went back to network time and the
original `home.conf` was restored afterwards. The longest case is the first row tied for the maximum trimmed length
(60 characters); the short case is the shortest authored row, so the author line is checked too.

| Language | Case | Day index / date | Exact text shown | Author line | Lines | Ellipsis |
| --- | --- | --- | --- | --- | --- | --- |
| ca | Longest | 3 / 2027-04-20 | Cal mantenir el vigor del cos per conservar el de l'esperit. | — Vauvenargues | 1 | None |
| ca | Short | 397 / 2028-05-18 | Gira full. | — Edmund Burke | 1 | None |
| es | Longest | 239 / 2027-12-12 | Más vale cien leguas de mal caminar que otras cien sin andar | None (traditional saying) | 2 | None |
| es | Short | 163 / 2027-09-27 | Da esperanza. | — Periandro | 1 | None |
| en | Longest | 18 / 2027-05-05 | Where there is the greatest love, there are always miracles. | — Willa Cather | 2 | None |
| en | Short | 155 / 2027-09-19 | Give hope. | — Periander | 1 | None |

In every case the quote sits under the date, the author line follows it, the whole text is visible (checked on the
screenshots, not only in the dump, which reports the full text even when a view is ellipsized), and the longest
lines take at most two lines of the 800 px-wide view. Evidence: `.state/v17-emulator/run2/quotes/` (PNG and XML
per case, plus `longest-crops.png`) and `.state/v17-emulator/run2/check.log`.
